# Tema 3. Formulación y nomenclatura inorgánica

## **1. Nomenclatura química**

En 2005, la IUPAC acordó unas normas para unificar la nomenclatura, en las que el **número de oxidación** es un concepto clave. Gracias a él, podemos conocer la estequiometría de un compuesto, es decir, el número de átomos de cada elemento que lo forman.

Se denomina **número de oxidación** a la carga formal que adquiriría un átomo si todos sus enlaces fueran 100 % iónicos. Por tanto, este número será positivo si pierden electrones y negativo si los ganan.

### **Valencia y número de oxidación** {: .caja-subtitulo #no-toc }
Valencia y número de oxidación son términos relacionados. Por ejemplo, si un elemento posee dos números de oxidación, decimos que posee dos valencias o que será divalente.

### **Tabla de números de oxidación** {: .caja-subtitulo #no-toc }

Los números de oxidación que aparecen encabezando o finalizando una familia se aplican a todos sus elementos.

![...](imagenes/tema03/estados_oxidacion.png){ style="display: block; margin: 0 auto; width: 100%; height: auto;" }

Algunos elementos poseen más números de oxidación, como el nitrógeno: -1, +1, +2, +3, +4, +5.

## **2. Iones**

### **2.1 Cationes** {: .caja-subtitulo}

Son los átomos que han perdido electrones y quedan con carga positiva. Esta carga coincide con su número de oxidación. Si hay más de un número de oxidación o valencia, dará lugar a cationes del mismo elemento con diferente carga.

**Fórmula:** $\ce{M^{n+}}$

**Nombre:** M (carga y signo)

| Ion | Nomenclatura | Ion | Nomenclatura | Ion | Nomenclatura | 
| ----- | ----- | ----- | ----- | ----- | ----- | 
| $\ce{Na+}$ | sodio(1+) | $\ce{Ca^{2+}}$ | calcio(2+) | $\ce{Ag+}$ | plata(1+) | 
| $\ce{Al^{3+}}$ | aluminio(3+) | $\ce{Ni^{2+}}$ | níquel(2+) | $\ce{Ni^{3+}}$ | níquel(3+) | 
| $\ce{Fe^{3+}}$ | hierro(3+) | $\ce{Fe^{2+}}$ | hierro(2+) | $\ce{Sn^{4+}}$ | estaño(4+) | 

### **2.2 Aniones** {: .caja-subtitulo}

Son átomos que han ganado electrones y quedan con carga negativa. Esta carga coincide con el número de oxidación.

**Fórmula:** $\ce{X^{n-}}$

**Nombre:** X-uro (carga y signo)

El paréntesis sigue al nombre sin ningún espacio. En el caso de que el número de oxidación sea único (monovalente), se puede omitir su valor.

| Ion | Nomenclatura | Ion | Nomenclatura | 
| ----- | ----- | ----- | ----- | 
| $\ce{Cl-}$ | cloruro(1-) o cloruro | $\ce{S^{2-}}$ | sulfuro(2-) o sulfuro | 
| $\ce{F-}$ | fluoruro |  | **Excepción:** | 
| $\ce{H-}$ | hidruro | $\ce{O^{2-}}$ | óxido | 
| $\ce{N^{3-}}$ | nitruro | $\ce{O2^{2-}}$ | peróxido o dióxido(2-) \*| 

\* Corresponde a lo que se denomina anión homopoliatómico.

### **2.3 Aniones poliatómicos** {: .caja-subtitulo}

Los aniones pueden estar formados por más de un elemento. En este caso, su nomenclatura y formulación se puede realizar de dos maneras:

### **A. Nomenclatura tradicional** {: .caja-subtitulo2 #no-toc }

Se utilizan prefijos y sufijos conforme al número de oxidación con que actúa el elemento que da lugar al anión. Se pueden presentar varios casos, según sea el número de valencias que posea dicho elemento:

| Ion | Grupo 17 | Grupo 16 | Grupo 15 | Grupo 14 |
| ----: | :---: | :---: | :---: | :---: |
| **per ... ato** | +7 | | | |
|     **... ato** | +5 | +6 | +5 | +4 |
|     **... ito** | +3 | +4 | +3 | +2 |
| **hipo ... ito** | +1 | +2 | | |

Para **obtener el numero de oxidación** del no metal se debe tener en cuenta que la suma de los estados de oxidación por cada elemento debe ser igual a la carga dada y que el oxígeno siempre actúa con estado de oxidación $\ce{- 2}$ y el hidrógeno, en caso de existir, actua con número de oxidación $\ce{+ 1}$.

**Ejemplos**: 

<div style="text-align: center; margin: 20px 0;">

<span style="border: 2px solid #34077d; border-radius: 12px; padding: 15px; display: inline-block; vertical-align: middle; background: #fafaf1; margin-right: 12px;">$\ce{ClO4^-}$</span> $\ce{\quad \rightarrow \quad X(Cl) + 4 * (-2) = - 1 \quad \rightarrow \quad X(Cl) = - 1 + 8 = + 7 }$ 

</div>

El cloro (grupo 17) actúa con estado de oxidación +7 luego el compuesto recibe el nombre de ion <strong>perclorato</strong>.

<div style="text-align: center; margin: 20px 0;">

<span style="border: 2px solid #34077d; border-radius: 12px; padding: 15px; display: inline-block; vertical-align: middle; background: #fafaf1; margin-right: 12px;">$\ce{PO3^{-3}}$</span> $\ce{\quad \rightarrow \quad X(P) + 3 * (-2) = - 3 \quad \rightarrow \quad X(P) = - 3 + 6 = + 3 }$ 

</div>

El fósforo (grupo 15) actúa con estado de oxidación +3 luego el compuesto recibe el nombre de ion **fosfito**.

<div style="text-align: center; margin: 20px 0;">

<span style="border: 2px solid #34077d; border-radius: 12px; padding: 15px; display: inline-block; vertical-align: middle; background: #fafaf1; margin-right: 12px;">$\ce{HSO4^{-}}$</span> $\ce{\quad \rightarrow \quad X(S) + 1 (+ 1) + 4 * (-2) = - 1 \quad \rightarrow \quad X(S) = - 2 + 8 = + 6 }$ 

</div>

El azufre (grupo 16) actúa con estado de oxidación +6 luego el compuesto recibe el nombre de ion <strong>hidrogenosulfato</strong>.

### **Formulación tradicional** {: .caja-subtitulo2 #no-toc }

Para **formularlos**, se escribe el no metal con su número de oxidación indicado por el prefijo y sufijo y, a continuación, se añaden tantos oxígenos como sean necesarios, considerando que cada oxígeno añadido aporta dos cargas negativas ($\ce{- 2}$), para que el ion quede con la mínima carga negativa posible.

Por ejemplo, el cloro tiene cuatro valencias, así que tendríamos las posibilidades:

**hipoclorito:** cloro (+1) $\quad$ **clorito:** cloro (+3) $\quad$ **clorato:** cloro (+5) $\quad$ **perclorato:** cloro (+7)

Ejemplos para obtener el anión:

Ion clorito: el cloro actúa con valencia 3. 

  $\ce{Cl^{3+} + O^{2-} = ClO+}$ (<span style="color:red">Incorrecto</span>)

  $\ce{Cl^{3+} + (O2)^{4-} = ClO2-}$ (Correcto)

Ion clorato: el cloro actúa con valencia 5. 

  $\ce{Cl^{5+} + O^{2-} = ClO^{3+}}$ (<span style="color:red">Incorrecto</span>)

  $\ce{Cl^{5+} + (O2)^{4-} = ClO2+}$ (<span style="color:red">Incorrecto</span>)

  $\ce{Cl^{5+} + (O3)^{6-} = ClO3-}$ (Correcto)


### **B. Nomenclatura de hidrógeno (adición)** {: .caja-subtitulo2 #no-toc }

Indicamos primero el número de oxígenos con prefijos numéricos seguido de la palabra **oxido**. A continuación, el elemento de la izquierda acabado en el sufijo **-ato**. Por último, indicamos la carga entre paréntesis al final y sin separación.

Si hay hidrógenos, esta palabra se antepone al resto, que se pone entre paréntesis:

$$
\text{Palabra hidrogeno-} + \text{(Prefijo numeral (oxido)} + \text{Nombre del elemento-ato}) + \text{(carga ion)}
$$

**Ejemplo:** $\quad \ce{HCO3-} \quad \rightarrow \quad \text{hidrogeno(trioxidocarbonato)(1-)} $

![...](imagenes/tema03/bicarbonato.png){ style="display: block; margin: 0 auto; width: 80%; height: auto;" }

Otros **ejemplos**: 

| Ion | Nomenclatura | Ion | Nomenclatura | 
| ----- | ----- | ----- | ----- | 
| $\ce{SO3^{2-}}$ | trioxidosulfato(2-) | $\ce{H2PO4-}$ | dihidrogeno(tetraoxidofosfato)(1-) | 
| $\ce{SO4^{2-}}$ | tetraoxidosulfato(2-) | $\ce{ClO3-}$ | trioxidoclorato(1-) | 
| $\ce{Cr2O7^{2-}}$ | heptaoxidodicromato(2-) | $\ce{MnO2-}$ | dioxidomanganato(1-) | 

**Importante**

- No hay que dejar espacio entre el nombre y el paréntesis.
- En palabras compuestas como los aniones poliatómicos y las sales y ácidos que de ellos se deriven, pierden la tilde todos los elementos. Así pues, en estos casos no deberás acentuar las partículas *oxido-* ni *hidrogeno-*.


## **3. Compuestos binarios**

Los compuestos binarios se forman por la unión de dos elementos, que se escriben de la siguiente forma:

<div style="text-align: center; margin: 20px 0;">

<span style="border: 2px solid #34077d; border-radius: 12px; padding: 15px; display: inline-block; vertical-align: middle; background: #f7c8b9; margin-right: 12px;">$\ce{M_x X_y}$</span>

</div>

* $\ce{M}$: El elemento menos electronegativo se escribe a la izquierda.

* $\ce{X}$: El elemento más electronegativo se sitúa a la derecha (con valencia negativa).

El orden creciente de electronegatividades, comenzando con el flúor y terminando con el radón, que la IUPAC ha establecido como referencia para la ordenación de los símbolos de los elementos en las fórmulas, es el siguiente:

![...](imagenes/tema03/electronegatividad.png){ style="display: block; margin: 0 auto; width: 100%; height: auto;" }

En la formación de un compuesto, asignamos a cada elemento una carga formal correspondiente al número de oxidación que utilice. Luego estos elementos se combinan en número de manera que la carga total sea nula.

### **Formulación** {: .caja-subtitulo2 #no-toc }

Una regla sencilla que, aunque con excepciones, puede ayudar a la formulación del compuesto, es el intercambio de valencias y la posterior simplificación.

**Ejemplo de formulación:**

Sulfuro de plomo(IV): $\quad$ formado por $\ce{Pb^{4+}}$ y $\ce{S^{2-}}$

Intercambio cruzado:* $\ce{\quad Pb_2S_4 \rightarrow (simplificaci\textrm{ó}n) PbS2}$*

![...](imagenes/tema03/sulfurodeplomo.png){ style="display: block; margin: 0 auto; width: 30%; height: auto;" }

### **Nomenclatura** {: .caja-subtitulo2 #no-toc }

En este curso utilizaremos dos tipos de nomenclatura:

1. **Prefijo multiplicador:** Se nombran de derecha a izquierda, de manera que leemos primero el elemento más electronegativo, acabado en el sufijo **-uro** (a excepción del oxígeno, que se lee como **óxido**), seguido del elemento de la izquierda. Se indica el número de cada átomo con prefijos numéricos (el término *mono-* se utilizará sobre el anión solo en el caso de que el elemento menos electronegativo posea más de una valencia).

2. **Números de oxidación:** No se introducen prefijos numéricos, únicamente el número de oxidación del elemento menos electronegativo (siempre elemento a la izquierda en la fórmula) entre paréntesis y en números romanos. En caso de que posea una única valencia, se omite el número.

![...](imagenes/tema03/oxidodesodio.png){ style="display: block; margin: 0 auto; width: 30%; height: auto;" }

En la formulación inorgánica según las recomendaciones de la IUPAC, varios elementos modifican su raíz (generalmente acortándose o recuperando su raíz latina) al añadir el sufijo -**uro**.

**1. No metales y semimetales (los más habituales)**

Estos son los cambios principales que aparecen en hidruros y sales binarias:

| Elemento | Nombre con -uro | Modificación que sufre |
| ----- | ----- | ----- | 
| Azufre (S) | Sulfuro | Cambia por completo su raíz por la latina (sulfur) | 
| Nitrógeno (N) | Nitruro | Pierde la terminación -ógeno |
| Hidrógeno (H) | Hidruro | Pierde la terminación -ógeno |
| Carbono (C) | Carburo | Pierde la terminación -ono |
| Fósforo (P) | Fosfuro | Pierde -oro (la forma fosforuro está en desuso) |
| Arsénico (As) | Arseniuro | Pierde -co y conserva la i antes del sufijo |
| Telurio (Te) | Telururo | Pierde la i final de la raíz (también se acepta teluro como nombre del elemento) |

**Ejemplos comparativa de ambas nomenclaturas**

| Compuesto | Nomenclatura (Prefijos) | Nomenclatura (Nº de oxidación) | 
| ----- | ----- | ----- | 
| $\ce{Li2O}$ | óxido de dilitio | óxido de litio | 
| $\ce{FeH2}$ | dihidruro de hierro | hidruro de hierro(II) | 
| $\ce{Cr2S3}$ | trisulfuro de dicromo | sulfuro de cromo(III) | 
| $\ce{N2O}$ | óxido de dinitrógeno | óxido de nitrógeno(I) | 
| $\ce{SI2}$ | diyoduro de azufre | yoduro de azufre(II) | 
| $\ce{BaH2}$ | dihidruro de bario | hidruro de bario | 

**Importante**

Con anterioridad a la publicación de las normas de la IUPAC del año 2005, los compuestos de oxígeno con un haluro se nombraban como los óxidos ($\ce{Cl2O}$ óxido de dicloro; $\ce{Cl2O5}$ pentaóxido de dicloro). Actualmente esta nomenclatura **no está aceptada**.

### **3.1 Peróxidos** {: .caja-subtitulo}

Los **peróxidos** son compuestos que se obtienen por la combinación entre un metal y el grupo peróxido o dióxido(2-) ($\ce{O2^{2-}}$). El subíndice del oxígeno forma parte del ion, por lo que no se puede eliminar. Se confunden fácilmente con los óxidos.

### **Nomenclatura** {: .caja-subtitulo2 #no-toc }

Sigue las mismas normas vistas anteriormente; están aceptados los dos nombres para el anión.

| Compuesto | Nombre sistemático | Nombre aceptado por la IUPAC | 
| ----- | ----- | ----- | 
| $\ce{Li2O2}$ | dióxido de dilitio | peróxido de litio | 
| $\ce{CaO2}$ | dióxido de calcio | peróxido de calcio | 
| $\ce{PbO2}$ | dióxido de plomo | peróxido de plomo(II) | 

### **Formulación** {: .caja-subtitulo2 #no-toc }

Sigue las mismas normas pero con la condición de que el subíndice del oxígeno no se puede eliminar.

**Ejemplos de formulación:**

| Nombre | Compuesto | Nombre | Compuesto | 
| ----- | ----- | ----- | ----- | 
| peróxido de oro(I) | $\ce{Au2O2}$ | dióxido de bario | $\ce{BaO2}$ | 
| triperóxido de dihierro / peróxido de hierro(III) | $\ce{Fe2(O2)3}$ | triperóxido de diníquel / peróxido de níquel(III) | $\ce{Ni2(O2)3}$ | 

**Importante**

Los peróxidos y los óxidos suelen confundirse cuando queremos nombrarlos. Una técnica para resolver este problema consiste en averiguar la valencia si fuera un óxido. Si dicha valencia no pertenece al elemento, nos encontramos con un peróxido.
Ejemplo: En $\ce{Na2O2}$, si fuera un óxido el sodio tendría valencia 2; como el sodio solo tiene valencia 1, en consecuencia, es un peróxido.

### **3.2 Hidróxidos** {: .caja-subtitulo}

Los **hidróxidos** son compuestos que se obtienen por la unión de un metal con el grupo hidróxido ($\ce{OH-}$). Aunque en este caso nos encontramos con tres elementos diferentes, su nomenclatura y formulación es idéntica a los compuestos binarios, pues se trata al grupo hidróxido como un conjunto de un solo elemento.

| Nombre | Compuesto | Nombre | Compuesto | 
| ----- | ----- | ----- | ----- | 
| hidróxido de aluminio / trihidróxido de aluminio | $\ce{Al(OH)3}$ | hidróxido de calcio / dihidróxido de calcio | $\ce{Ca(OH)2}$ | 
| hidróxido de níquel(II) / dihidróxido de níquel | $\ce{Ni(OH)2}$ | hidróxido de plomo(IV) / tetrahidróxido de plomo | $\ce{Pb(OH)4}$ | 

### **3.3 Hidrógeno + no metal** {: .caja-subtitulo}

El hidrógeno actúa con estado de oxidación +1 y los no metales con su respectivo estado de oxidación negativo. Los compuestos de los grupos 13, 14 y 15 son hidruros y tienen nombre común aceptado.

### **Ácidos hidrácidos en disolución acuosa** {: .caja-subtitulo2 #no-toc }

Las disoluciones acuosas de los compuestos entre el hidrógeno y los elementos de los grupos 16 y 17 tienen un comportamiento ácido y se nombran con la palabra **ácido** seguida del elemento con el sufijo **-hídrico**:

- $\ce{HF (ac)}$: ácido fluorhídrico
- $\ce{HCl (ac)}$: ácido clorhídrico
- $\ce{H2S (ac)}$: ácido sulfhídrico
- $\ce{H2Se (ac)}$: ácido selenhídrico

En este caso no se nombra un compuesto puro, sino una disolución, por lo que no pertenece a la nomenclatura química formal.

## **4. Compuestos ternarios**

Los compuestos ternarios están formados por tres elementos diferentes. Su nomenclatura y formulación resulta más compleja. Trataremos dos tipos: los oxoácidos y las oxisales.

### **4.1 Oxiácidos (Oxoácidos)** {: .caja-subtitulo}

Los ácidos oxoácidos son compuestos formados por un no metal, oxígeno e hidrógeno, cuya fórmula general es:

<div style="text-align: center; margin: 20px 0;">

<span style="border: 2px solid #34077d; border-radius: 12px; padding: 15px; display: inline-block; vertical-align: middle; background: #f9f7fb; margin-right: 12px;">$\ce{H_a X_b O_c}$</span> (siendo X el no metal)

</div>

Veremos dos formas de nombrar estos compuestos:

### **A. Nomenclatura tradicional** {: .caja-subtitulo2 #no-toc }

Para aprender a formular este tipo de compuestos hay que conocer los números de oxidación con los que los no metales pueden actuar. Estos son los siguientes:

| Familia | Grupo | Números de oxidación | 
| ----- | ----- | ----- |
| Halógenos | 17 | +1, +3, +5, +7 |
| Ánfígenos | 16 |+2, +4, +6 |
| Grupo del N | 15 |+3, +5 |
| Grupo del C | 14 |+2, +4| 

 Al darnos la fórmula del ácido tenemos que deducir el número de oxidación del elemento central X (+n), que será igual al doble de oxígenos que tenga menos los hidrógenos. 

Ejemplo: $\quad \ce{H2SO4} \quad \rightarrow \quad \ce{4 (O) * 2 - 2 (H) = 6}$

Si del elemento central tenemos varios átomos el resultado lo dividimos por ese número.

Ejemplo: $\quad \ce{H2Cr2O7} \quad \rightarrow \quad \dfrac {\ce{7 (O) * 2 - 2 (H)}}{\ce{2 (Cr)}} = \dfrac {14-2}{2} = 6 $

La IUPAC admite la nomenclatura tradicional, que utiliza el nombre genérico de **ácido** y los prefijos y sufijos **hipo- -oso**, **-oso**, **-ico** y **per- -ico**.

| Ácido | Grupo 17 | Grupo 16 | Grupo 15 | Grupo 14 |
| ----: | ----- | ----- | ----- | ----- |
| **Ácido $\quad$ per ... ico** | +7 | | | |
|     **Ácido $\quad$ ... ico** | +5 | +6 | +5 | +4 |
|     **Ácido $\quad$ ... oso** | +3 | +4 | +3 | +2 |
| **Ácido $\quad$ hipo ... oso** | +1 | +2 | | |

Ejemplo: $\quad \ce{H2SO4}$

Antes se dedujo que el S actua en este compuesto con número de oxidación de +6, en consecuencia, se llamaría **ácido** sulfúr**ico**.

### **Formulación** {: .caja-subtitulo2 #no-toc }

A **partir de los prefijos y sufijos** deducimos el número de oxidación del **elemento central**. El hidrógeno tiene número de oxidación $\ce{+ 1}$ y el oxígeno $\ce{- 2}$. Buscamos luego unos coeficientes que hagan que la carga aportada por los oxígenos sea igual y de signo contrario a la aportada por los hidrógenos y el elemento central.

Para calcular la fórmula directa $\ce{HaXbOc}$, se puede usar esta regla mental muy rápida:

Ponemos siempre los elementos en orden: $\ce{\quad H}$ (hidrógeno), $\ce{X}$ (no metal), $\ce{O}$ (oxígeno)

El **hidrógeno** ($\ce{H}$) suele llevar un subíndice fijo según la valencia del no metal: 

 - Si la valencia del no metal es **impar** (1, 3, 5, 7), el hidrógeno lleva un 1 (no se pone).

    Excepción: **P**, **As**, **Sb** con valencia 3 o 5 llevan 3 hidrógenos.
 
 - Si la valencia del no metal es **par** (2, 4, 6), el hidrógeno lleva un 2. 

El **oxígeno** ($\ce{O}$) se calcula con una cuenta muy fácil:

$$\ce{\text{Nº de Oxígenos} = \frac{\text{Valencia del no metal} + \text{Subíndice del Hidrógeno}}{2}}$$

**Ejemplo 1**: $\quad$ Ácido hipocloroso.

El cloro pertenece al grupo 17 y según el nombre -**hipo ...oso**, actua con el número de oxidación más bajo, $\ce{+ 1}$, luego tendremos que poner un hidrógeno por ser impar. 

Impar $\ce{\rightarrow HClOc}$

$\ce{\text{Nº de Oxígenos} = \dfrac{\text{Valencia del no metal} + \text{Subíndice del Hidrógeno}}{2} = \dfrac{\ce{1 + 1}}{\ce{2}} = 1 }$

Fórmula final: $\quad$ <span style="background-color: #fedbdb; border: 1px solid #2563eb; border-radius: 4px; padding: 2px 6px;">$\ce{HClO}$</span>

**Ejemplo 2**: $\quad$ Ácido fosfórico. 

El fósforo pertenece al grupo 15 y según el nombre -**ico**, actua con número de oxidación $\ce{+ 5}$, a pesar de ser impar es una de las expciones luego tendremos que poner tres hidrógenos. 

Impar $\ce{\rightarrow H3POc}$

$\ce{\text{Nº de Oxígenos} = \dfrac{\text{Valencia del no metal} + \text{Subíndice del Hidrógeno}}{2} = \dfrac{\ce{5 + 3}}{\ce{2}} = 4 }$

Fórmula final: $\quad$ <span style="background-color: #fedbdb; border: 1px solid #2563eb; border-radius: 4px; padding: 2px 6px;">$\ce{H3PO4}$</span>

**Ejemplo 3**: $\quad$ Ácido sulfúrico. 

El azufre pertenece al grupo 16 y según el nombre -**ico**, actua con número de oxidación $\ce{+ 6}$, luego al ser grupo par tendremos que poner un hidrógeno. 

Par $\ce{\rightarrow H2SOc}$

$\ce{\text{Nº de Oxígenos} = \dfrac{\text{Valencia del no metal} + \text{Subíndice del Hidrógeno}}{2} = \dfrac{\ce{6 + 2}}{\ce{2}} = 4 }$

Fórmula final: $\quad$ <span style="background-color: #fedbdb; border: 1px solid #2563eb; border-radius: 4px; padding: 2px 6px;">$\ce{H2SO4}$</span>

### **B. Nomenclatura de hidrógeno** {: .caja-subtitulo2 #no-toc }

Se nombra primero el hidrógeno (utilizando **-hidrogeno-**, sin acento), indicando su cantidad con prefijos; entre **paréntesis**, a continuación, se nombra el oxígeno (utilizando **-oxido-**, sin acento) y el elemento no metálico acabado siempre en **-ato**.

Ejemplo: $\quad \ce{H2SO4}$

![...](imagenes/tema03/acidosulfurico.png){ style="display: block; margin: 0 auto; width: 80%; height: auto;" }

### **Formulación** {: .caja-subtitulo2 #no-toc }

Se van leyendo los prefijos del compuesto de izquierda a derecha pero invertimos el orden entre el no metal y el oxígeno (óxido)

### **4.2 Oxisales** {: .caja-subtitulo}

Las **oxisales** son compuestos formados estructuralmente por un catión (siempre un metal o ion $\ce{NH4^+}$, amonio) y un anión que proviene del ácido oxoácido correspondiente.

### **Formulación de las sales** {: .caja-subtitulo2 #no-toc }

Para **formularlas**, primero se escribe el catión y luego el anión. Al leer la fórmula, el orden seguido es el inverso. Las cargas de los iones se intercambian, simplificando si llegase el caso.

Se utilizan los mismo prefijos que en los oxoácidos sustituyento **-ico** por **-ato** e **-oso** por **-ito** y perdiendo el nombre de ácido.

| Oxoácido | Anión | N.O. Grupo 17 | N.O. Grupo 16 | N.O. Grupo 15 | N.O. Grupo 14 |
| ----: | ----- |  ----- | ----- | ----- | ----- |
| **Ácido $\quad$ per ... ico** | **per ... ato** | +7 | | | |
|     **Ácido $\quad$ ... ico** | **... ato** | +5 | +6 | +5 | +4 |
|     **Ácido $\quad$ ... oso** | **... ito** | +3 | +4 | +3 | +2 |
| **Ácido $\quad$ hipo ... oso** |**hipo ... ito** | +1 | +2 | | |

Ejemplos:

* **Nitrato de sodio:** ion nitrato ($\ce{NO3-}$) + ion sodio ($\ce{Na+}$) $\ce{\rightarrow Na+ + NO3-  = NaNO3}$

* **Sulfato de calcio:** ion sulfato ($\ce{SO4^{2-}}$) + ion calcio $\ce{Ca^{2+}}$ $\ce{\rightarrow Ca^{2+} + SO4^{2-} = Ca2(SO4)2 = CaSO4}$

* **Fosfato de hierro(II):** ion fosfato ($\ce{PO4^{3-}}$) + ion hierro(II) $\ce{Fe^{2+}}$ $\ce{\rightarrow Fe^{2+} + PO4^{3-} = Fe3(PO4)2 }$

### **A. Nomenclatura tradicional** {: .caja-subtitulo2 #no-toc }

Para **nombrarlas** hay que nombrar el anión y añadirle el nombre del catión indicando su valencia entre paréntesis y en números romanos, si tiene más de una.

| Oxisal | Catión | Anión | Nombre | 
| ----- | ----- | ----- | ----- | 
| $\ce{LiNO2}$ | $\ce{Li+}$ | $\ce{NO2-}$ | nitrito de litio | 
| $\ce{Fe2(CO3)3}$ | $\ce{Fe^{3+}}$ | $\ce{CO3^{2-}}$ | carbonato de hierro(III) | 

### **B. Nomenclatura sistemática de composición** {: .caja-subtitulo2 #no-toc }

Se nombra el anión con la terminación **-ato**; si hay más de uno, se indica con un prefijo numeral multiplicativo (*bis-*, *tris-*, *tetraquis-*, *pentaquis-*, *hexaquis-*). A continuación, la preposición **de** y el nombre del catión con prefijos numéricos.

Ejemplo: 

$$
\ce{Co2(CO3)3} \quad \rightarrow \quad \text{tris(trioxidocarbonato) de dicobalto}
$$
